# LiveWall

Lightweight live wallpapers for Windows 10/11: videos, GIFs, 3D models and web pages behind your desktop icons, with very low memory use.

## Download
**[⬇ LiveWall-win-Setup.exe](https://github.com/SlaughterSensei/LiveWall-releases/releases/latest/download/LiveWall-win-Setup.exe)** (latest version)

Run it to install. It installs for your user account only, no admin needed, and keeps itself up to date automatically.

Windows may show a SmartScreen warning because the installer isn't code-signed. Click **More info → Run anyway**.

## Features
- Videos (mp4, webm, mkv, mov), animated GIF/WebP, 3D models (glb, gltf, obj, fbx, stl, ply) and web pages as wallpaper
- A built-in **Browse online** tab for free videos and 3D models (Poly Haven, Khronos, Wikimedia Commons, Pexels, Pixabay)
- Multi-monitor support. Screens covered by fullscreen or maximized apps pause automatically.
- OLED care: pure black backgrounds, a slow picture shift and dimming on the monitor you choose
- Automatic updates

This repository only hosts the installer and updates.
